# Geological Mines

**Deployment: Server-only.** No Krasnokamen Loader is required; an ordinary vanilla 26.1.2 client can use this plugin.

This startup-only example selects the `realistic_deposits` worldgen ore profile. Install it only for a fresh Krasnokamen world whose persisted generation contract should use large deterministic cross-chunk deposits, or enable the bundled id `geological-mines`.
